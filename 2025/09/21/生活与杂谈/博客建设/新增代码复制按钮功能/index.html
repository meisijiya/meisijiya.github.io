我的完善后的code-copy.js版本：

关键样式参数

  • position: ‘absolute’, // 相对于代码块定位
  • right: ‘8px’, // 距右边 8px
  • top: ‘8px’, // 距顶部 8px
  • zIndex: 99, // 低于导航栏的 100

功能流程

  1. 页面加载完成后，遍历所有 figure.highlight 代码块
  2. 为每个代码块添加复制按钮（如果不存在）
  3. 鼠标悬停时按钮变清晰
  4. 点击后：
    • 从 td.code 获取代码文本
    • 调用 navigator.clipboard.writeText() 复制
    • 显示绿色对勾图标，1 秒后恢复

在页面底部引入 JS 文件：打开文件themes/hexo-theme-Chic/layout/_partial/footer.ejs。

在 </footer> 标签之后添加以下代码：<script src="/js/code-copy.js"></script>
