00 Go 系列总览

18 篇按「语言基础 → 复合数据结构 → 并发 → 工程实战 → 面试复盘」排列的 Go 学习文档，从装工具链一路走到能讲清楚一个生产级项目。

0.1 这套文档解决什么问题

学 Go 的资料满地都是，真正缺的是一条能走完的路径。市面上的内容通常掉进两个坑：

  • 语法字典式灌输：把变量、循环、函数挨个念一遍，看完还是不会写。
  • 跳过基础直接上框架：上来就 Gin + GORM，出了并发问题根本不知道是 channel 用错还是 map 没加锁。

这套文档的做法是：每一篇都按「概念 → 可运行代码 → 与 Java/Python 的差异 → 什么时候会踩坑 → 动手练」五段式展开，读的时候手边一定要有编辑器。

有 Java 或 Python 基础的话，01~07 篇一周内能过完；后面的并发与实战是拉开差距的部分。

0.3 三种学习节奏

节奏 周期 怎么用 适合谁
速通 7 天 0107 每天一篇，0814 只读「坑」小节，15~16 只跑不写 已有其他语言基础、只为过面试
系统 14 天 每天一篇 + 动手练全部做完，第 15~16 篇完整跟着敲 准备把 Go 当主力语言
项目驱动 一个月 先扫 01/03/05/06，其余按需查，直接开 15~16，遇到不会再回来补 已有工程经验、想要作品

不管哪种节奏，动手练都别跳。 切片、map、channel 这三个坑，看懂和写对之间隔着一整个编译期。

0.4 环境准备

编辑器建议 VS Code + Go 官方扩展：保存即编译、gopls 跳转、格式化用 gofmt。

版本这件事要说清楚

Go 每半年发一个大版本，新语法由 go.mod 里的 go 指令决定是否生效，而不是由你装的是哪个工具链决定：

版本 关键变化 影响
1.22 循环变量每轮新建、for range 覆盖整数、ServeMux 支持方法与通配符 写新代码的最低版本线
1.23 range 覆盖函数（迭代器）、iter 包、slices/maps 扩展 遍历抽象统一
1.24 泛型类型别名、go.mod 的 tool 指令、testing.B.Loop、map 换 Swiss Tables 实现 工具链与性能
1.25 sync.WaitGroup.Go、容器感知 GOMAXPROCS 并发写法更短
1.26 new(expr) 带初值、Green Tea GC 默认开启 运行时与 GC
1.27 泛型方法、encoding/json/v2 转正、goroutine 泄漏 profile 语言与可观测性

go.mod 里的 go 指令写成 go 1.22 及以上，上面这些新语法才会启用；写低了会直接编译报错。

0.7 动手练清单（学完就能打卡）

  • 用 := 和 var 各写一遍声明，说清两者差别
  • 写一个函数返回 (int, error)，并用 errors.Is 判断具体错误
  • 打印 append 前后的 len 和 cap，观察扩容点
  • 制造一次「两个切片共享底层数组」的 bug，再修掉
  • 写一个生产者-消费者：用带缓冲 channel 传数据，用 close 通知结束
  • 写一个 sync.WaitGroup 版的多任务等待，并跑 go test -race 验证
  • 用 chi 起一个服务，注册两条路由 + 一个鉴权中间件
  • 把上面这些串成一个能跑的 RSS 抓取小工具

0.8 写在最后

Go 的学习曲线前段平缓（语法三天能上手），后段陡峭（并发与工程化能劝退一批人）。这套文档把陡的那段拆成了 08~16 共九篇，每篇都配了能跑的代码。

先跑起来，再谈优化。 祝学习顺利。
