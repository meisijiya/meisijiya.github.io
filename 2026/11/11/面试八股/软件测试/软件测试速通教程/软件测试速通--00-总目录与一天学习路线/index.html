Hi，我是 meisijiya ，也是 老江湖 ，感谢你的阅读，我们一起进步。

你在准备软件测试实习面试，手上有黑马课件、几篇博客笔记和一堆招聘启事，缺的是一份能照着走的顺序。这套教程把岗位、设计、流程、案例、工具、接口、性能、AI 与笔试串成十篇，读完你能自己拆需求、写用例、走一遍测试流程，并在面试里把每一步讲清楚。

二、一天 8 小时学习路线

判断：一天之内把主线走完，靠的是把「读」和「做」绑定，每 30–60 分钟必须留下一个能拿出手的东西。

时间 读哪篇哪节 做什么 产出物
08:00–08:20 00 全文 确认顺序 工具清单勾选表
08:20–09:10 01 七类岗位分型、团队分工矩阵 从 5 个招聘启事里圈硬门槛词 岗位拆解表
09:10–10:20 02 等价类、边界值、判定表、状态迁移、场景法 拿登录需求写有效/无效类；给下单流程画状态迁移 两页用例草稿 + 状态表
10:20–11:20 03 十阶段总表、需求评审与测试计划、缺陷到上线 写一页测试计划；把一条缺陷走完整生命周期 一页测试计划 + 缺陷单
11:20–12:20 午休 — —
12:20–13:30 05 工具手册（Linux、MySQL、抓包、ADB、Postman） 在本机跑通一个 GET 并写一条断言 命令速查卡 + 一条可跑的断言
13:30–14:30 06 接口十要素、三层断言、pytest 骨架 把骨架跑起来，跑 2 条用例 一个能跑的骨架
14:30–15:20 04 案例库：登录、支付、权限、弱网 把 04 的测试点树模板套到一个自己的需求上 一套自己的测试点树
15:20–16:00 07 指标口径、JMeter 元件顺序、报告解读 读一份聚合报告并写出结论 指标口径卡
16:00–17:10 08 AI 辅助流水线与 AI 产品测试 用提示词生成 10 条用例并人工打标 提示词模板 + 评测集样例
17:10–18:10 09 六方向 JD、20 问骨架、场景题、笔试 口述 5 题并录音；做 10 道 pytest 装饰器题 录音 + 笔试错题本

工具安装单独占 30 分钟，放在 08:00 之前或当晚收尾时段，清单见第五节。

读不完怎么办：主线是 01→02→03，这三篇不能跳；04 以后按投递方向挑。投功能测试，读 04、05；投接口自动化或测试开发，读 05、06；投 AI 测试，读 08、09。把一天拆成两天也可以，但顺序不要打乱，后面的篇会直接引用前面的术语和模板。

时间不够的取舍顺序：先砍 07，再砍 04 的 App 部分，08 与 09 不能砍。

学完这八小时，做三件验收：拿一段需求能写出十条以上用例；能说清一次缺陷从提交到关闭的五个状态；能对着一份招聘启事说出对方要的是哪一类测试岗。三件都做到，就去投。

四、每篇怎么用：固定三节与自测

判断：每篇末尾的三节是给你「收口」用的，读完正文不等于会用，走完这三节才算。

节 怎么用 花多久
🗣️ 面试怎么说 直接念，念到不看稿 5 分钟
✅ 自测 5 题 先写答案再对，错题回正文找依据 10 分钟
📚 来源 需要引原文时按图索骥 2 分钟

建议顺序：先读正文一遍 → 做自测 5 题 → 错的回看对应小节 → 最后念「面试怎么说」。自测题不是考记忆，是考「能不能用一句话给出判断」。三节里最容易跳过的是自测，也最容易在面试里暴露，别省。

常见误区有三个。第一个是只读不写，读完觉得自己懂了，一开口写用例就卡住；每个演练都要动笔，笔迹比阅读记得牢。第二个是抄答案，自测题照抄正文里的句子没有意义，要合上正文用自己的话说。第三个是追新，术语背到一半就去追某个框架的新版本，岗位要求的是能用，不是知道最新特性。

五、工具准备清单（不装也能读）

判断：工具是拿来练手的，不是门槛；装不上就跳过对应小节，正文照样能读。

工具 用途 装不上就跳过
Python 3.10+ 写 pytest 脚本 06 的骨架代码
pytest 跑自动化用例 06 全部
Postman 接口调试 06 接口十要素实操
Git 版本管理 05 的 Git 5 条
ADB 连手机、抓日志 05 的 ADB 8 条
JMeter 性能压测 07 全部
Charles 抓包、弱网 05 的抓包节
Appium App 自动化 06 的 App 自动化
Allure 测试报告 06 的落地验收

必装四项：Python、pytest、Postman、Git。选装四项：JMeter、Charles、Appium、Allure。装不上的替代方案：用在线接口文档代替 Postman、用同学电脑代替真机、用代码托管网站的 Web 界面代替本地 Git。

安装顺序：先 Python → 再 pytest（pip install pytest requests）→ 再 Postman → 再 Git → 最后选装。每装完一个，跑一条最小验证：

Windows 上有两个坑提前说：JMeter 安装路径避免空格与中文（含空格是官方明确会出问题的情况，中文路径在国内环境也常出问题）；Postman 与 Charles 都要在代理设置里放开本地回环，否则抓不到包。

🗣️ 面试怎么说

  • 我这周把测试主线过了一遍：从岗位分型到用例设计到完整流程，能独立拆一个登录需求并写出用例。
  • 我习惯按「需求 → 测试点 → 用例 → 执行 → 缺陷 → 报告」这条线做事，每步都留产出物。
  • 我不会一上来就测，先做需求评审，把理解一致了再动手。
  • 工具上我会 Python、pytest、Postman 和 Git，抓包用 Charles，性能会用 JMeter 跑基础场景。
  • 我清楚测试岗的产出物是质量信号：用例、自动化、缺陷报告，而不是只报一个「测完了」。
