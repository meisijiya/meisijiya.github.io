近年来的AI技术栈

作者: 老江湖
日期: 六月 3, 2026  22:12:21
分类: AI

大模型原理详解：从输入层到输出层

第一部分：训练数据的准备

1.1 自回归模型的核心思想

大模型的核心任务只有一个：预测下一个词。

训练阶段：每次向模型输入一批数据，告诉模型准确答案是什么。每个预测词都会计算一个损失值，所有词的平均损失用于反向传播更新参数。

推理阶段（自回归）：输入一句话后，模型生成同样长度的词，将最后一个词作为本次预测结果，拼接到输入文本末尾，让模型继续预测下一个词。重复这个动作，模型就不断生成新词，直到输出特殊结束标志（EOS）。

1.2 数据准备完整流程

第一步：分词与构建词典

  1. 对海量文本进行分词，每个词就是一个 token（中文叫词元）
  2. 对所有词元去重，得到庞大的词典
  3. 对词元编号，得到词元→ID 映射表
  4. 将映射关系对调，得到ID→词元 映射表

第二步：添加结束标志

在每句话末尾添加一个特殊标志（如 EOS），表示句子结束。这个标志也是学习目标之一——模型在海量数据中学习该在什么时候输出这个标志，也就相当于学会了什么时候结束发言。

第三步：采样训练数据

每个训练数据由输入-目标数据对组成。

以 context_length=3、stride=2（移动步长）为例：

输入 目标
词1 词2 词3 词2 词3 词4
词3 词4 词5 词4 词5 词6
… …

训练时，模型根据三个输入 token 输出三个 token，前两个是给预测阶段用的，最后一个才是真正的预测结果。

关键参数说明：

参数 含义 说明
context_length 上下文长度 决定模型能处理多长的上下文，GPT-2 是 1024，主流模型已有 128K
stride 移动步长 设置小→重复多；设置大→重复少，数据量足够时建议设大避免过拟合
batch_size 批次大小 每次输入模型的样本数，越大训练越快但显存需求越高

1.3 BPE 分词法

传统分词法以完整词为单位，但无法覆盖所有词汇（未登录词问题）。

BPE（Byte Pair Encoding）将单词进一步拆分为更细粒度的子元素（词根、字母），遇到未登录词时继续拆分，最小拆成单个字母。这些子元素通常携带丰富语义信息（如 “impossible” 中的 “im” 表示否定）。

优势：可以处理任何未见过的词汇。

第二部分：嵌入层

2.1 词嵌入（Word Embedding）

文本无法直接进行数学计算，需要转化为向量。嵌入层完成这个转换。

词汇表矩阵：行数 = 词表大小（如 50257），列数 = 嵌入维度

嵌入维度（Embedding Dimension）：768（GPT-2）。维度越大，涵盖信息量越多，但计算量也越大。

2.2 位置向量（Positional Encoding）

词嵌入只表示词语本身的含义，但位置信息对语义至关重要：

“屡败屡战”不失为一个英雄，”屡战屡败”却是一个十足的狗熊。

位置向量的两种表示方法：

方法一：训练得到（GPT-2 采用）

  • 设定一个位置向量矩阵，行数 = context_length，列数 = 嵌入维度
  • 每个位置对应一个随机初始化的向量
  • 训练过程中作为参数一起更新

方法二：公式计算（Transformer 原论文）

$$PE(pos, 2i) = \sin(pos / 10000^{2i/d_{model}})$$
$$PE(pos, 2i+1) = \cos(pos / 10000^{2i/d_{model}})$$

  • pos：位置序号（从 0 开始）
  • i：维度索引
  • d_model：嵌入维度

2.3 绝对位置 vs 相对位置

类型 说明
绝对位置 “我”在第 2 个位置，位置编号是 1
相对位置 “我”相对于”冬瓜”的位置是 -1

相对位置编码更常用，因为对语义理解来说，词语之间的距离比词语在哪个位置更重要。

2.4 嵌入向量如何通过反向传播更新？

问题：直接用 key-value 方式查表是不可导的，无法传播梯度。

解决方案：用矩阵乘法实现查表操作。

  1. 将词元 ID 转为 one-hot 向量（长度 = 词表大小，只有该 ID 位置是 1）
  2. 用 one-hot 向量乘以词元向量矩阵

由于 one-hot 向量只有目标位置是 1，其他位置都是 0，因此矩阵相乘的结果恰好等价于从词元向量矩阵中取出对应位置的向量。这个操作是可导的，梯度可以通过矩阵乘法反向传播到词元向量矩阵中。

最终嵌入向量 = 词元向量 + 位置向量

第三部分：Transformer 核心——注意力机制

3.1 注意力机制的本质

目标：让每个 token 能够捕捉到其他 token 的注意力信息。

核心思想：新向量 = 旧向量的加权求和，权重就是注意力得分。

示例：对于”小猫在沙发上玩耍”这句话中的”玩耍”：
- 注意力镜头 1：重点捕捉”小猫”，确定动作主体
- 注意力镜头 2：聚焦”沙发”，明确发生位置
- 注意力镜头 3：扫描整句，感受整体氛围

3.2 注意力得分计算

以 token2 为例：

  1. 点积计算：token2 与所有 token 进行向量点积
    attention_score = X2 · Xj (j = 1, 2, 3)
  2. Softmax 归一化：将得分转为概率分布（所有权重和为 1）
    weight = softmax(attention_scores)
  3. 加权求和：用归一化后的权重对所有向量加权求和，得到新的 token2

3.3 掩码机制（Masking）

问题：如果让 token2 在计算注意力时就”看见”了 token3，就相当于训练时把答案泄露给模型，模型会”偷看”答案而不真正学习。

解决方案：掩码机制——在计算注意力时，隐藏当前 token 之后的所有 token。

实现方法：
- 计算点积后、Softmax 前，把当前 token 之后的注意力得分全部改为 -∞
- 由于 $e^{-\infty} \approx 0$，Softmax 后这些位置的权重就是 0

效果：注意力矩阵的上三角被遮住，模型无法提前”看到”答案。

何时可以不用掩码？ 做”完形填空”题目时。

3.4 QKV 机制

问题：一个向量同时做三件事（查询、被查询、被加权），容易”精神分裂”，导致语义冲突。

解决方案：引入三个参数矩阵，将角色拆分，各司其职。

矩阵 角色 含义
W_Q 查询（Query） “我想要什么”
W_K 键（Key） “我能提供什么”
W_V 值（Value） “我的实际内容是什么”

3.5 矩阵视角下的注意力计算

“远交近攻”口诀：
- 近攻：两个矩阵相乘的前提是”靠得近”的维度要相等
- 远交：结果矩阵的形状 = “离得远”的两个维度

注意力计算的矩阵运算：

d_k 缩放（除以 √d_k）的原因：

现象 原因 解决方案
QK相乘后数值波动大 点积后标准差变成 √d_k 除以 √d_k 使标准差恢复到 1
直接 Softmax 后很多权重变成 0 数值差异过大 缩放后 Softmax 分布更均匀

3.6 多头注意力（Multi-Head Attention）

动机：一句话中可能存在多种需要捕捉的注意力关系，单一头注意力无法全面覆盖。

实现方式：

  1. 将输入矩阵兵分多路
  2. 每路独立计算注意力，有各自的 W_Q、W_K、W_V
  3. 将所有注意力头的输出拼接（Concat）

维度设计：

这样设计的好处是：既捕捉多维度注意力，又不增加输出维度。

3.7 FFN（前馈神经网络）

多头注意力输出后，进入 FFN 层：

  • 第一层：将向量投影到更高维空间（d_ff 通常是 d_model 的 4 倍）
  • 激活函数：引入非线性表达能力
  • 第二层：投影回原始维度

为什么这样设计？ 通过升维→降维的操作，将输入向量投影到更高维的特征空间，学习更复杂的特征表示。虽然形状不变，但向量”到更广阔的天地遨游了一番”。

3.8 多层 Transformer

整个 Transformer 模块的输入输出维度必须一致，因此可以堆叠多层。

逐层提取特征：

层级 图像模型 语言模型
浅层 提取线条、纹理 识别单词基础语义
中层 组成局部特征（鼻子、眼睛） 学习相连词的关系
深层 拼装整体画面（猫/狗） 理解句子完整含义

预训练与微调的基础：多层结构使模型可以作为特征提取器，方便预训练和后续微调。

第四部分：训练中的工程技巧

4.1 梯度消失与梯度爆炸

问题 1：训练不稳定

随着层数加深，前向传播的数据分布会逐渐偏离，反向传播的梯度也会剧烈变化。80 层收到的数据可能比 7-9 层大了一万倍，导致参数更新失控。

解决方案：归一化（Layer Normalization）

归一化后，数据被压缩为均值为 0、方差为 1的分布，梯度更可控。

注意：归一化改变了绝对值，但相对大小不变，原信息依然保留。

问题 2：梯度消失

反向传播时，梯度需要从最后一层一层层传回前面的层，每层都”漏一点”，传到第 10 层时可能几乎为 0 了。

解决方案：残差连接（Residual Connection）

在 Transformer 中添加”直通车”：将前一层的输入与输出相加后再传入下一层。

即使梯度很小，起码有”1”兜底。相当于把最后一层的梯度直接传到第 10 层，解决了梯度消失问题。

4.2 过拟合与 Dropout

问题：大模型太强了，容易”背答案”，训练损失低但测试效果差。

解决方案：Dropout

每次训练时随机丢弃一部分神经元（如 20%）：

  1. 随机挑选若干神经元，将输出设为 0
  2. 这些神经元不参与本次前向传播
  3. 反向传播时，这些神经元的梯度也为 0

效果：
- 避免某个神经元”一家独大”主导决策
- 所有神经元能力得到平衡
- 增强模型的泛化能力

细节：
- 丢弃比例是需要设置的参数（如 20%）
- Dropout 只发生在训练阶段，推理时所有神经元都参与
- 训练时丢弃了 20%，输出要放大 1/(1-0.2)=1.25 倍，维持原本的输出期望

第五部分：输出层

5.1 损失函数计算（训练阶段）

数据准备：训练阶段，每个输入 token 都有对应的目标 token 和损失值。

计算过程：

损失函数本质：交叉熵损失。损失值越低，说明模型对目标词的预测概率越高。

5.2 采样策略（推理阶段）

问题：不能简单选概率最高的词（贪心策略），会导致：

  1. 相同输入永远输出相同结果
  2. 局部最优不一定带来全局最优

解决方案：按概率抽样

所有词都有机会被选中，概率高的词选中机会更大。

Top-K 采样：只保留概率最高的 K 个词，在这 K 个词中按概率抽样。

Top-P 采样：按照概率从大到小取，累积概率达到 P%（如 90%）的词入选，灵活动态。

Temperature（温度参数）：

temperature 值 效果
> 1 分布更均匀，输出更多样
< 1 分布更集中，输出更确定

组合使用：一般官方文档都有推荐参数，照着抄作业即可。

总结：大模型架构全景图

参数分布（GPT-2 为例）：
- 词嵌入层：约 4000 万参数
- 注意力层：多头注意力的 QKV 参数
- FFN 层：最大的参数来源（约 4 倍嵌入维度）
- 层数越多，参数总量越大

关键影响因素：层数（Layer Number）和 FFN 中间层维度是决定模型参数量最关键的因素。
