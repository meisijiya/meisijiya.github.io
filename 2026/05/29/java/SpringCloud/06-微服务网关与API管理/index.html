API网关作用与架构设计

1.1 什么是API网关 🚪

API网关是微服务架构中的统一入口，负责请求路由、负载均衡、安全认证、限流熔断等功能。

核心作用：

  • 统一入口：所有请求通过网关进入
  • 路由转发：根据路径转发到不同服务
  • 负载均衡：集成Ribbon/LoadBalancer
  • 安全认证：JWT验证、OAuth2
  • 限流熔断：集成Sentinel/Hystrix
  • 日志记录：请求日志、链路追踪
  • 协议转换：HTTP ↔ gRPC

Spring Cloud Gateway核心概念

2.1 Gateway概述 🌟

Spring Cloud Gateway是Spring Cloud官方提供的API网关，基于WebFlux构建，提供路由转发、负载均衡、安全认证、限流熔断等功能。

核心特性：

  • 路由转发：根据路径转发到不同服务
  • 负载均衡：集成Ribbon/LoadBalancer
  • 过滤器链：请求和响应过滤
  • 限流熔断：集成Sentinel/Hystrix
  • 安全认证：JWT、OAuth2

2.2 Gateway架构 🏗️

2.3 核心概念详解 📚

1. 路由（Route）：

  • 路由是网关的基本单元
  • 由ID、URI、断言、过滤器组成
  • 根据断言匹配请求

2. 断言（Predicate）：

  • 断言用于匹配请求
  • 支持多种断言类型
  • 可以组合多个断言

3. 过滤器（Filter）：

  • 过滤器用于处理请求和响应
  • 分为前置过滤器和后置过滤器
  • 可以自定义过滤器

4. 负载均衡（Load Balancer）：

  • 集成Ribbon/LoadBalancer
  • 支持多种负载均衡策略
  • 自动发现服务实例

面试常见问题与答案

Q1：API网关的作用是什么？

答案：

API网关的作用：

  1. 统一入口：

    • 所有请求通过网关进入
    • 简化客户端调用
    • 统一管理API

  2. 路由转发：

    • 根据路径转发到不同服务
    • 支持动态路由
    • 支持灰度发布

  3. 负载均衡：

    • 集成Ribbon/LoadBalancer
    • 支持多种负载均衡策略
    • 自动发现服务实例

  4. 安全认证：

    • JWT验证
    • OAuth2授权
    • API密钥验证

  5. 限流熔断：

    • 控制请求速率
    • 防止服务雪崩
    • 保护系统资源

  6. 日志记录：

    • 请求日志
    • 链路追踪
    • 性能监控

Q2：Spring Cloud Gateway和Zuul有什么区别？

答案：

对比维度 Spring Cloud Gateway Zuul
开发公司 Spring Cloud官方 Netflix
底层框架 WebFlux（Reactor） Servlet
性能 高，非阻塞IO 低，阻塞IO
长连接 支持WebSocket 不支持
限流 集成Sentinel/Redis 需要额外实现
过滤器 GatewayFilter ZuulFilter
维护状态 活跃维护 已停止维护

Gateway优势：

  • 性能更高，非阻塞IO
  • 支持WebSocket长连接
  • 官方推荐，持续维护
  • 与Spring Cloud生态集成更好

Q3：Gateway的路由断言有哪些类型？

答案：

Gateway路由断言类型：

  1. 路径断言（Path）：

    • 匹配请求路径
    • 支持Ant风格路径
    • 示例：Path=/api/user/**

  2. 方法断言（Method）：

    • 匹配HTTP方法
    • 支持多个方法
    • 示例：Method=GET,POST

  3. 头部断言（Header）：

    • 匹配请求头
    • 支持正则表达式
    • 示例：Header=X-Request-Id, \d+

  4. 参数断言（Query）：

    • 匹配请求参数
    • 支持参数值匹配
    • 示例：Query=username, zhangsan

  5. 时间断言（After/Before/Between）：

    • 匹配请求时间
    • 支持时区
    • 示例：After=2024-01-01T00:00:00+08:00[Asia/Shanghai]

  6. 主机断言（Host）：

    • 匹配主机名
    • 支持通配符
    • 示例：Host=**.example.com

  7. Cookie断言（Cookie）：

    • 匹配Cookie
    • 支持正则表达式
    • 示例：Cookie=sessionId, \d+

Q4：如何实现网关的限流？

答案：

网关限流实现方式：

  1. 基于Redis的限流：

    • 使用Redis计数器
    • 支持分布式限流
    • 实现简单

  2. 基于Sentinel的限流：

    • 集成Sentinel限流
    • 支持多种限流策略
    • 功能完善

  3. 基于令牌桶的限流：

    • 使用令牌桶算法
    • 允许突发流量
    • 实现复杂

  4. 基于漏桶的限流：

    • 使用漏桶算法
    • 流量平稳
    • 实现复杂

限流策略：

  • 基于IP限流
  • 基于用户限流
  • 基于路径限流
  • 基于参数限流

Q5：如何保证网关的高可用？

答案：

网关高可用方案：

  1. 集群部署：

    • 部署多个网关实例
    • 使用负载均衡器
    • 支持故障转移

  2. 负载均衡：

    • 使用Nginx负载均衡
    • 支持多种负载均衡策略
    • 健康检查

  3. 服务发现：

    • 集成注册中心
    • 自动发现服务实例
    • 支持动态路由

  4. 故障隔离：

    • 熔断机制
    • 降级策略
    • 限流保护

  5. 监控告警：

    • 性能监控
    • 日志记录
    • 告警通知
