4.4 进程与线程

基本概念

概念 说明 类比
进程（Process） 操作系统分配资源的基本单位 打开一个浏览器 = 一个进程
线程（Thread） CPU 调度的最小执行单元 浏览器内的下载/渲染/交互

一个进程至少有一个线程。多任务的 3 种模式：多进程、多线程、多进程+多线程。

多进程

多线程

线程锁：

GIL（全局解释器锁）—— Python 多线程的”坑”

CPU 密集型任务：多线程不能并行利用多核（GIL 限制）
IO 密集型任务：多线程可以提高效率（IO 时会释放 GIL）

场景 推荐方案
CPU 密集（计算） multiprocessing 多进程
IO 密集（网络/文件） threading 多线程 或 asyncio
两者都要 多进程 + 每个进程内多线程

三语对照：多线程

本章小结

知识点 Python 关键点 TS/Java 差异
✅ 文件读写 with open() as f: 自动管理 TS: fs 模块; Java: try-with-resources
✅ JSON json.dumps/loads 内置支持 TS 内置; Java 需第三方库
✅ 正则 re.match/search/findall TS: /pattern/.test(); Java: .matches()
✅ 多进程 multiprocessing.Process Node: child_process; Java: ProcessBuilder
✅ 多线程 threading.Thread + GIL 注意 TS: worker_threads; Java: Thread
✅ 锁 with lock: 上下文管理 TS/Java 也有类似机制
