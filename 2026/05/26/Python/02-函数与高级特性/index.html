本章小结

知识点 Python 要点 TS/Java 差异
✅ 函数定义 def f(): TS: function f() / Java: 返回类型 f()
✅ *args / **kwargs 可变参数/关键字参数 TS: 剩余参数 ...args; Java: int... nums
✅ lambda lambda x: expr x => expr (TS) / x -> expr (Java)
✅ 列表生成式 [x*x for x in range(10)] TS: .map(); Java: stream
✅ 生成器 yield 惰性求值 TS: function*; Java: 无（Stream 近似）
✅ 装饰器 @decorator 动态增强 TS: @Decorator; Java: @Annotation + AOP
✅ map/filter/reduce Python 内置 TS/Java 都有，Java 在 Stream API 中
