3.1 模块与包（Module & Package）

为什么需要模块？

当代码变多时，把函数/类分到不同 .py 文件中。

一个 .py 文件 = 一个模块（Module）。

模块的好处

好处 说明
✅ 可维护性 每个文件职责单一
✅ 可复用 写好的模块到处导入
✅ 命名空间 不同模块的同名函数不会冲突

导入模块

包（Package）

包 = 按目录组织的模块集合。**每个包目录必须包含 __init__.py**。

3.2.2 访问限制

Python 没有真正的 private，靠命名约定：

访问控制 Python TypeScript Java
公有 name public name public name
私有 __name（约定） #name (ES2022+) / private name private name
保护 _name（约定） protected name protected name

Python 没有真正的 private——全靠程序员自觉。俗话说的好：”我们都是成年人了。”

本章小结

知识点 Python 关键点 TS/Java 差异
✅ 模块 import x / from x import y TS: import {y} / Java: import x.Y
✅ 类 class A:，self 必须显式 TS/Java 的 this 可选
✅ 继承 class Dog(Animal): 括号写法 TS: extends / Java: extends
✅ 私有 __name 命名约定 TS: #name / Java: private
✅ 多态 鸭子类型（无接口约束） TS: 接口 / Java: 接口
✅ @property Python 特有 getter/setter 语法 Java 需手动写 getter/setter
✅ 错误 try/except/else/finally try/catch/finally（没有 else）
