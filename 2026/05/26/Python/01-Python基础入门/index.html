01 Python 基础入门

目标读者：有 JS/TS 或 Java 基础的初学者。我们会三语对照，帮你快速从已知迁移到 Python。

1.1 认识 Python

它从哪来？

  • 作者：Guido van Rossum（荷兰人，人称”龟叔”）
  • 诞生：1989 年圣诞节（打发无聊写的）
  • 设计哲学：优雅 · 明确 · 简单——尽量写容易看懂的代码

它能干什么？

领域 代表库/框架
🌐 Web 后端 Flask, Django, FastAPI
🤖 自动化脚本 内置 os, shutil
📊 数据科学 NumPy, Pandas
🧠 AI / 机器学习 PyTorch, TensorFlow
🔧 运维工具 Ansible, SaltStack

Python vs TS vs Java：语言定位

特性 Python TypeScript Java
类型系统 动态（运行时检查） 静态（编译时检查） 静态（编译时检查）
语法风格 缩进驱动 花括号 {} 驱动 花括号 {} 驱动
运行方式 解释执行 编译 → JS 执行 JVM 字节码
典型场景 脚本/数据/后端 前端/全栈/Node 后端 企业后端/Android

1.3 Python 语法基础

1.3.1 缩进规则（最重要的区别！）

Python 不用花括号，用缩进表示代码块。

语言 代码块标识
Python 缩进（推荐 4 空格）
TypeScript {} 花括号
Java {} 花括号

⚠️ 不要混用 Tab 和空格！设置编辑器把 Tab 自动转成 4 空格。

1.5.3 dict（字典）≈ TS 对象 / Java HashMap

操作 Python dict TypeScript Object Java HashMap
取值 d['key'] obj['key'] 或 obj.key map.get("key")
赋值 d['key'] = v obj.key = v map.put("key", v)

⚠️ dict 的 key 必须为不可变类型（字符串、整数、tuple），list 不可以当 key。

本章小结

知识点 Python 关键点 TS/Java 差异提醒
✅ 缩进 4 空格定义代码块 TS/Java 用 {}
✅ 变量 动态类型，无需声明 TS/Java 需要类型声明
✅ 字符串 f'{name}' 最常用 TS 模板字面量类似
✅ list 下标从 0，切片 [start:end:step] 类似但语法不同
✅ dict d.get(key) 安全取值 Java 用 getOrDefault
✅ 条件 elif 不是 else if else if (TS/Java)
✅ 循环 for x in iterable TS: for...of, Java: for-each
