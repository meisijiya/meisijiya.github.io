信息处理技术员-考前半个钟速通

作者: 老江湖
日期: 五月 23, 2026  7:30:00
分类: 软考

考前 30 分钟救命稻草，全是考点中的考点，一句废话没有。

⚡ 考场策略（考前必看）

📚 Part A：上午题核心速记（选择题 75 道）

一、信息处理基础（17~23 分，占比最高）

1. 数据 vs 信息

概念 关键词 口诀
数据 物理符号、载体、未加工 数载（数据是载体）
信息 内涵、意义、加工后 信涵（信息是内涵）

🔥 必考：信息同物质、能源并列为世界三大资源（第四资源=智能）

2. 数据 9 大性质（必考 9 个）

口诀：**”普客识动时，传共价不”**

# 性质 含义
1 普遍性 无处不在
2 客观性 客观真实
3 识别性 可被识别
4 动态性 随时间变
5 时效性 过期无效
6 传递性 可传输
7 共享性 非消耗/可共享
8 价值性 有使用价值
9 不完全性 有局限性

3. 信息技术四大分类

口诀：**”感通算计”**

类别 功能 类比 典型
感测技术 获取信息 感官 传感器、GPS
通信技术 传递信息 神经系统 光纤、5G
计算机技术 处理信息（核心） 大脑 CPU、AI
控制技术 利用信息 行动器官 机器人、PLC

4. 信息化六要素

口诀：**”资网技产人规”**

# 要素 地位
1 信息资源 核心与基础
2 信息网络 重要支撑
3 信息技术 推动力
4 信息产业 经济基础
5 信息化人才 关键
6 政策法规 保障

5. 编码校验

校验码 位数 用途
身份证 18 位 最后一位是校验码（0-9 或 X）
ISBN 13 位 最后一位校验码
奇偶校验 — 只能检错，不能纠错

二、计算机系统基础（6~17 分）

1. 冯·诺依曼五大部件

部件 英文 功能
运算器 ALU 算术运算+逻辑运算
控制器 CU 取指令→译码→执行（只发命令，不处理数据）
存储器 Memory 存储程序和数据
输入设备 Input 键盘鼠标等
输出设备 Output 显示器打印机等

🔥 CPU = 运算器 + 控制器

2. 存储器对比（必考）

类型 特征 断电后
RAM（内存） 可读可写，速度快 ❌ 数据丢失
ROM（只读） 只读，存 BIOS ✅ 数据保留
Cache（缓存） SRAM，速度最快，容量最小 ❌ 数据丢失
HDD（机械硬盘） 容量大、怕震动 ✅ 保留
SSD（固态硬盘） 速度快、不怕震动、擦写次数有限 ✅ 保留

3. 存储单位换算

4. 图像/音频格式

格式 类型 压缩 特点
BMP 位图 不压缩 体积最大
JPEG/JPG 位图 有损 照片常用
PNG 位图 无损 支持透明 ✅
GIF 位图 无损 仅 256 色、可动图
WAV 音频 不压缩 体积大、音质好
MP3 音频 有损 最普及
MIDI 音频 — ⚠️ 不是波形，是指令序列！

5. 打印机区分

类型 场景 耗材
激光 办公文档 碳粉（速度快）
喷墨 家用/彩色打印 墨水
针式 多联票据 色带（唯一可复写纸打印）

三、计算机网络与操作系统（4~18 分）

1. 网络分类

类型 范围 速度
LAN（局域网） 一栋楼 最快
MAN（城域网） 一座城市 中等
WAN（广域网） 全球 最慢

2. OSI 七层模型（必考顺序）

口诀：**”物数网传会表应”**（从下到上）

层 功能 典型协议
物理层 传输比特流 RJ45、光纤
数据链路层 帧传输、MAC 地址 MAC、以太网
网络层 路由选择、IP 地址 IP、路由器
传输层 端到端传输 TCP、UDP
会话层 建立会话连接 —
表示层 数据格式转换、加密 —
应用层 用户接口 HTTP、FTP、DNS、SMTP

🔥 TCP/IP 四层：应用层(对应OSI 5-7) + 传输层 + 网络层 + 网络接口层(对应OSI 1-2)

3. IP 地址分类（必考）

类别 首字节范围 默认子网掩码 记忆
A 1~126 255.0.0.0 A=1
B 128~191 255.255.0.0 B=128
C 192~223 255.255.255.0 C=192

🔥 127.0.0.1 = 本机环回地址（ping 自己用）

4. 私有 IP（内网地址）

| A 类 | 10.0.0.0 ~ 10.255.255.255 |
| B 类 | 172.16.0.0 ~ 172.31.255.255 |
| C 类 | 192.168.0.0 ~ 192.168.255.255 ← 最常见 |

5. Windows 快捷键（高频）

快捷键 功能
Ctrl+C / Ctrl+V / Ctrl+X 复制/粘贴/剪切
Ctrl+Z / Ctrl+Y 撤销/恢复
Ctrl+A 全选
Ctrl+S 保存
Ctrl+Shift+Esc 任务管理器
Alt+F4 关闭当前窗口
Win+D 显示桌面
Win+E 文件资源管理器
Win+L 锁定
F2 重命名
Shift+Delete 彻底删除

6. 文件命名规则

Windows 不允许的字符：\ / : * ? " < > |
Windows 不区分大小写

四、信息安全与法律法规 + 英语（8~13 分）

CIA 三要素

口诀：**”机完可”**

要素 英文 含义
机密性 Confidentiality 不被未授权访问
完整性 Integrity 不被篡改
可用性 Availability 需要时可用

知识产权保护期限（年年考）

类型 期限
个人著作权 终生 + 死后 50 年
法人著作权 发表后 50 年
发明专利 20 年
实用新型专利 10 年
外观设计专利 10 年（新法 15 年）
商标 10 年，到期可无限续展

⚠️ 署名权、修改权、保护作品完整权 → 永久保护，无时间限制！

病毒特征

特征 说明
传染性 最核心特征
隐蔽性 隐藏在正常程序中
潜伏性 感染后不立即发作
破坏性 破坏系统或数据
可触发性 满足条件时发作

防火墙

  • 不能防内部攻击
  • 不能防病毒
  • 只是第一道防线

英语高频词汇（5 分）

英文 中文
Information 信息
Data 数据
Software / Hardware 软件 / 硬件
Security 安全
Network 网络
Database 数据库
Encryption / Decryption 加密 / 解密
Application 应用程序
Confidentiality 机密性
Integrity 完整性
Availability 可用性

五、数据库基础（1~4 分）

  • 主键：唯一标识一条记录，不能重复、不能为空
  • 外键：引用另一张表的主键
  • 实体关系：1:1、1:N（最常见）、M:N（需要中间表）
  • E-R 图三要素：□ 矩形（实体）、◇ 菱形（联系）、○ 椭圆（属性）
  • SQL 基础：
    • SELECT ... FROM ... WHERE ... ORDER BY ...
    • INSERT INTO ... VALUES (...)
    • UPDATE ... SET ... WHERE ...（⚠️ 必须有 WHERE）
    • DELETE FROM ... WHERE ...（⚠️ 必须有 WHERE）

七、Excel 操作核心速查（最难，分值最高）

必考函数公式速记

函数 语法 用途 星级
SUM =SUM(区域) 求和 ★★★
AVERAGE =AVERAGE(区域) 求平均 ★★★
MAX / MIN =MAX(区域) 最大/最小值 ★★★
COUNT =COUNT(区域) 数字计数 ★★
COUNTA =COUNTA(区域) 非空计数 ★★★
COUNTIF =COUNTIF(区域,"条件") 条件计数 ★★★★
SUMIF =SUMIF(条件区,"条件",求和区) 条件求和 ★★★★
IF =IF(条件,"是","否") 条件判断 ★★★★★
ROUND =ROUND(数值,2) 保留2位小数 ★★★★
RANK =RANK(数据,区域,1) 排名(1升序/0降序) ★★★★★
VLOOKUP =VLOOKUP(查谁,在哪查,第几列,FALSE) 纵向查找 ★★★★★

VLOOKUP 四大雷区（最容易丢分）

绝对引用 vs 相对引用

引用 写法 拖拽效果
相对引用 A1 随拖拽变化
绝对引用 $A$1 固定不动
混合引用 $A1 / A$1 行/列一个固定一个变

🔥 F4 键快速切换引用类型

图表选择原则

需求 图表
对比大小 柱形图
变化趋势 折线图
占比分析 饼图（只能一个系列！）

排序与筛选

  • 排序：必须选中整个数据区域，不能只选一列！
  • 多关键字排序：主关键字相同→按次关键字
  • 筛选：开始→排序和筛选→筛选

🚨 易错点 TOP 15（考前必过一遍）

# 易错点 ✅ 正确
1 运算器 = 控制器 运算器计算、控制器指挥
2 RAM 断电保留数据 ❌ RAM 断电丢失数据
3 ROM 完全不能写 考试默认为只读，但实际有些可擦写
4 MIDI 是音频波形 ❌ MIDI 是指令序列，不是波形
5 GIF 支持真彩色 ❌ GIF 只有 256 色
6 PNG 是有损压缩 ❌ PNG 是无损压缩、支持透明
7 VGA 传音频 ❌ VGA 只传视频模拟信号
8 1MB = 1000KB ❌ 1MB = 1024KB
9 杀毒软件是应用软件 ✅ 按软考教材=系统工具=系统软件
10 饼图可表示多个系列 ❌ 饼图只能表示一个数据系列
11 排序只选一列就行 ❌ 必须选整个数据区域
12 VLOOKUP 第四参可不写 ❌ 不写默认 TRUE，必须写 FALSE
13 分页符=分节符 ❌ 分节符才能实现不同页眉/纸向
14 嵌入型图片可自由拖动 ❌ 需改为四周型才能自由拖动
15 Windows 文件名区分大小写 ❌ Windows 不区分

📋 考前检查清单

  • 准考证、身份证带齐
  • 提前至少 1 小时到考场
  • 上午题：先易后难，不会的标记，最后蒙
  • 上午考完尽快交卷（30 分钟后），为下午抢休息时间
  • 下午题：每做完一题 Ctrl+S
  • 下午文件名按要求命名，不要漏扩展名
  • 函数公式写完拖拽填充，检查结果是否合理
  • VLOOKUP 记住四个要素：查谁、在哪、第几列、FALSE
  • 交卷前确认所有文件已保存到正确位置

🎯 最后一句：这考试难度不高，过线 45 分就行。上午靠刷题感觉 + 速记表，下午靠操作熟练度。稳住心态，能过的！
