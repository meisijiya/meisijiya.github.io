1. JavaScript 是什么？

1.1 一句话理解 🔑

JavaScript 是一种运行在浏览器中的脚本语言，用来给网页添加交互功能。

1.2 历史与现状

  • 1995 年：网景公司 Brendan Eich 用 10 天设计出 JavaScript（最初叫 LiveScript）
  • 1996 年：微软推出 JScript，浏览器大战开始
  • 1997 年：ECMAScript 1.0 标准发布，统一语法规范
  • 2009 年：ES5 发布（strict mode、JSON、数组新方法等）
  • 2015 年：ES6（ES2015）发布，是 JS 历史上最大的一次升级
  • 2016 至今：每年发布一个新版本（ES2016 ~ ES2025），持续进化
  • 2009 年 Node.js 诞生：JS 从此可以跑在服务器端

📌 关键概念：JavaScript ≠ Java，两者除了名字相似，没有任何关系！

1.3 JS 能做什么？

领域 说明
🌐 网页交互 表单验证、动画效果、数据展示
🖥️ 服务端开发 Node.js（Express/Koa/NestJS）
📱 移动 App React Native、Flutter（Dart，但理念相通）
🖥️ 桌面应用 Electron（VS Code、Slack 就是用 JS 写的）
🎮 游戏开发 Cocos2d-js、Phaser、Three.js（3D）
🤖 物联网 Ruff、Johnny-Five 控制硬件

1.4 浏览器如何执行 JS？

浏览器由两部分组成：

  • 渲染引擎：解析 HTML + CSS，画出网页（如 Chrome 的 Blink）
  • JS 引擎：解析和执行 JavaScript（如 Chrome 的 V8）

⚠️ 注意：<script> 标签会阻塞 HTML 解析！通常放在 </body> 之前，或使用 defer / async 属性。

2. JS 的组成：ECMAScript + DOM + BOM

组成部分 全称 作用 示例
ECMAScript 核心语法标准 变量、函数、对象、循环等基础语法 let a = 1; function fn(){}
DOM Document Object Model 操作 HTML 页面元素 document.getElementById()
BOM Browser Object Model 操作浏览器窗口 window.alert()、location.href

🧠 记忆口诀：ECMAScript 是”语言本身”，DOM 是”操作页面”，BOM 是”操作浏览器”。

12. 异步编程：从回调到 Promise 到 async/await

12.1 JavaScript 为什么需要异步？

JS 是单线程的，一次只能做一件事。如果网络请求要等 3 秒，期间页面就会卡死。所以耗时操作（网络请求、定时器、文件读取等）必须是异步的。

16. 总结与学习路线

🗺️ 推荐学习路线

🔑 五个核心心法

  1. JS 是弱类型动态语言 —— 变量类型运行时确定，要时刻注意 === vs ==
  2. 理解 this 的四条规则 —— 全局/方法/构造函数/箭头，面试必考
  3. 闭包 = 函数记住了它的出生地 —— 回调、数据私有化、模块化的底层机制
  4. 异步不等于多线程 —— JS 是单线程的，靠事件循环实现”并发”
  5. ES6+ 不是可选项 —— let/const、箭头函数、解构、Promise 已是现代 JS 的基本功
