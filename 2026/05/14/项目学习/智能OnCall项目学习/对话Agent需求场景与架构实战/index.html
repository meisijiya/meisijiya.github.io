1. 前置准备：对话Agent的需求、场景、价值分析

💡 对话Agent是什么？

对话Agent 是基于AI技术的智能交互系统，采用 AI + 知识库 模式，可将团队知识转化为活知识，避免因人员流动流失。

😫 需求背景：运维痛点

痛点 具体表现 影响
重复工作消耗人力 同类问题反复被问、反复回答 专家时间被低价值工作占用
工单堆积噪音多 大量简单工单堆积 真正的问题被淹没
响应不及时 业务方等待1小时+ 业务受损、满意度下降
知识流失 人员离职带走经验 新人上手困难

🎯 应用场景

场景 用户 典型问题 价值
业务方支持 产品/运营/测试 “这个接口报错怎么处理？” 减少研发被打扰
值班自救 值班研发 “Redis连接池满了怎么办？” 快速定位问题
工单预处理 工单系统 自动分类、简单问题自动处理 减少人工工单量

4. 面试话术与总结

🎯 面试话术模板

面试官：”介绍一下你的对话Agent项目”

你：

“这是一个基于AI的智能运维助手，核心解决三个痛点：

  1. 重复问题消耗人力
  2. 响应不及时
  3. 知识流失

技术架构：

  • RAG召回：问题向量化 → Milvus检索 → 获取相关文档
  • Prompt构建：整合角色、RAG上下文、工具说明、对话历史
  • ReAct模式：思考-行动-观察循环，支持多轮工具调用

核心价值：

  • 响应速度从1小时 → 秒回（60x提升）
  • RAG准确率从65% → 92%
  • 一次性解决率从50% → 80%

技术栈：Spring Boot + Spring AI Alibaba + Milvus + DashScope”
